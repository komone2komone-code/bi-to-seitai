# 美と整体

YouTube動画の「必要な区間」だけを登録し、毎日の整体・ストレッチをまとめて実行するための個人用Webアプリです。

## 第1版でできること

- YouTube URLを登録
- 開始時間・終了時間を指定
- 部位別に整理
- 「今日のメニュー」を作成
- 今日のメニューを順番に再生
- 上下ボタンで順番変更
- メモ保存
- ブラウザの localStorage に保存
- 「引き継ぎ」からJSONバックアップを書き出し／読み込み
- スマホ表示対応

## 使い方

YouTube埋め込みを安定して使うため、GitHub PagesなどのWeb公開環境で使うのがおすすめです。

1. GitHub Pagesでアプリを開く
2. 「＋ 整体を追加」
3. 名前・部位・YouTube URL・開始・終了を入力
4. 必要なら「今日のメニューに追加」
5. ホームの `START` で順番に再生

時間は `3:12` のような形式でも、秒数 `192` でも入力できます。

## GitHub Pages で公開する場合

このフォルダ内のファイルをGitHubリポジトリのルートに置き、
GitHub Pagesの公開元を `main / root` に設定すれば動作します。

## データについて

登録内容はGitHubには保存されません。
ブラウザの `localStorage` に保存されます。

ただし、リポジトリをPublicにする場合は、HTML/JS/CSS内に
個人情報・APIキー・パスワード・認証情報・非公開URLなどを書き込まないでください。

## 動画の扱い

このアプリはYouTube動画をダウンロード・複製せず、
YouTube公式の埋め込みプレーヤーで指定区間を再生します。
